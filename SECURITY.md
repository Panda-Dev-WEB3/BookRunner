# Security policy

Bookrunner is live on Robinhood Chain Testnet. Report a vulnerability privately, never in a public issue:

- GitHub private advisory: https://github.com/Panda-Dev-WEB3/BookRunner/security/advisories/new
- Email: contact@bookrunner.tech

Include the affected component (contract, service, site or app), the commit or deployed address, the steps to
reproduce and the impact you observed. Reports in English or French are welcome.

Scope and severity: [docs/BOUNTY_SCOPE.md](docs/BOUNTY_SCOPE.md). The web server's hardening is described in
[deploy/server/HARDENING.md](deploy/server/HARDENING.md).

The machine-readable contact file is published at https://bookrunner.tech/.well-known/security.txt
(source: `apps/site/public/.well-known/security.txt`; renew its `Expires` date before it lapses).
